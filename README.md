## 先搞清楚：这是专线服务器，不是机场订阅

很多人搜"沪美 IPLC"时以为买的是代理订阅，其实不是。Mkcloud 交付的是一台 VPS：每台机器分配 1 个独立入口 IP 和 1 个独立出口 IP（进+出各一个），你连入口操作服务器，里面的程序自动从美国出口向外访问。

这和机场的差别很实际。机场卖流量、多用户共享、节点质量看运气；专线服务器是你的独立机器，IP 只给你一个人用，适合跑美区店铺后台、海外办公系统、API 调用、文件同步这类需要稳定环境的事。

但反过来，它也有明确的边界：出口 IP 不支持外部连入，官方明确说不能拿来承载买家访问页面、支付回调、公开网站或游戏服务端。它是一台"你从国内连上去、再从美国向外发起访问"的机器，方向别搞反。

## 下单前必须知道的几条规则

这几条直接写在官方购物车页面，属于"不看会后悔"级别：

1. **需要中国身份信息实名**。所有专线产品都要求实名，仅限个人或企业正规用途。
2. **禁止机场、回国等用途**，一经发现清退且不退款。
3. **省级白名单限制**：上海电信直连版只允许一个省份的 IP 连入，下单时在附加选项里选省份，开通后可以自行切换到其他省份。
4. **退款政策严格**：仅支持质量问题退款，且需要提供准确的延迟数据、速度数据来证明问题；开通后不支持更换到其他地域的产品。
5. **只支持支付宝付款**，暂无其他支付方式。
6. **无默认 SLA**：官方明确不承诺无中断或固定故障恢复时长，对连续性要求高的业务先通过工单确认。
7. **升降级走工单**：降级到更低价格套餐时差价不退；快照和备份不在产品能力范围内，重要数据自己定期备份。

现货通常自动开通，官方口径约 1 分钟，实际受支付和系统安装影响会略有浮动。

结合上面的价格和限制，编辑判断如下：

- **美区店铺后台、日常办公、API 调用**：沪美 IPLC 流量计费 1TB 档足够，¥428/月用 MK-8.8 后约 377 元，是大多数人实际会买的档位。
- **素材上传、大数据量持续同步**：先估算月流量，2TB 以上直接看 4TB 档；如果流量是持续型而非突发型，独享 5M/10M 档不限流量反而更划算。
- **业务已经跑在阿里云/腾讯云上**：沪美 IX 是同配置下的最低价，1TB 档 ¥266/月，US-6.9 码如果能用还能再低，前提是你能接受云厂 BGP 前置这个条件。
- **多入口冗余需求**：上海电信和上海 BGP 是两条独立入口路径，有条件的话分别测试实际线路再定，官方 FAQ 也明确说两者没有固定的优劣等级。

还有一点别误解：124~134ms 是端内（入口到出口）的参考延迟，不是你本地到美国网站的全程耗时。全程还要加上本地到上海入口、美国出口到目标服务器的路径，测速时按官方知识库的方法分段看，避免误判。

## 常见问题

**沪美 IPLC 能看 Netflix、解锁流媒体吗？** 官方明确说明出口是服务器 IP，不保证原生、住宅属性或流媒体解锁。买它的定位是业务用途，不要按娱乐需求下单。

**IP 会不会被平台标记？** 每台独享 IPv4 只给一户使用，独立 IP 相对干净是这类产品的卖点，但官方不承诺平台账号不被限制，风控取决于平台自身策略。

**上海电信入口和 BGP 入口怎么选？** 官方建议按你实际使用的宽带和所在省份测试后决定，两者是并列候选，不是等级关系。

**能开发票、能定制配置吗？** 定制需求官方支持议价，独享产品页留有定制档位；发票和商务条款建议下单前直接通过工单确认。

**支持和家里宽带直连吗？** 直连版绑定省份白名单后允许对应省份 IP 连入；IX 版不行，必须通过支持的云厂网络接入，普通本地宽带无法直连。

沪美方向的选择逻辑其实不难：先确认用途合规（实名、正规业务）、再确认接入条件（能不能云厂前置、省份白名单是否影响你）、最后按流量模式选流量计费还是独享带宽。价格表都在上面，下单前把优惠码在购物车里试一遍，能省一点是一点。
